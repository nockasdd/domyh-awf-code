# 🔄 LEVEL 3: REFRAME — Change perspective COMPLETELY

## INVERT — Reverse all hypotheses
- "If ALL the code is CORRECT, where does the bug come from?"
- "Is the error message MISLEADING?"
- "Am I fixing the SYMPTOM or the ROOT CAUSE?"

## RUBBER DUCK — Explain from scratch
1. What SHOULD the program do? (expected)
2. What does it ACTUALLY do? (actual)
3. What path does data take input → output? (flow)
4. At each step, is the data in correct format? (validate)
5. At which step does data START going wrong? (pinpoint)

## DEVIL'S ADVOCATE — Self-contradict
- "What HARM could the proposed fix cause?"
- "In what scenario does the fix NOT work?"
- "How would an adversary break this fix?"

## FRESH EYES — Forget everything, read code from scratch
- Signature → docstring → line-by-line → boundaries → returns
