# Core Reference

Reference data for shared patterns, templates, and supporting agent material.

This directory is intentionally lightweight in the public repo and acts as the
stable target for manifest references used by loaders and validators.

| `GRAPH_SCHEMA.yaml` | 1.0.0 | CodeGraph node/edge type definitions |
